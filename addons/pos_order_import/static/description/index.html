POS Order Import

Batch import POS orders from CSV or Excel files

Import external platform orders (Shopee, momo, etc.) into POS as batch orders. Orders are created with Customer Account (pay later) payment method, and stock is deducted from the selected POS store's warehouse.

Features

  • CSV and Excel (.xlsx) file support
  • Downloadable sample templates
  • Product matching by name, internal reference, or barcode
  • Per-store warehouse isolation
  • Pay-later payment (receivable until platform remits)
  • Strict or flexible error handling
  • Bilingual: English + Traditional Chinese
