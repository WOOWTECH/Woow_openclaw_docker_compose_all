# Task: 錯誤根因分析與修復建議

## Description
分析失敗測試根因（code bug vs LINE API 限制 vs 設定問題 vs 測試問題），產出根因報告含修復建議。

## Role
錯誤解析專家

## Acceptance Criteria
- [ ] 每個失敗測試有明確的根因分類（code bug / LINE API 限制 / 設定問題 / 測試問題）
- [ ] 修復建議具體可行，指出需修改的檔案與方法
- [ ] 根因報告含優先順序排序
- [ ] 區分需程式碼修復 vs 設定調整 vs 測試修正的項目

## Technical Details
- 根因分類：
  - Code bug：程式碼邏輯錯誤，需修改 Python/JS/XML
  - LINE API 限制：LINE Platform 端限制，需調整實作策略
  - 設定問題：ir.config_parameter 或環境變數設定錯誤
  - 測試問題：測試本身邏輯有誤，需修正測試
- 每個根因需提供具體修復步驟
- 標注影響範圍（哪些模組/repo 需要修改）
