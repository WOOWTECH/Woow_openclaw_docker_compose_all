# Task: Agent — Dashboard OAuth Flow Builder

## Description

在 `/opt/hermes/tools/mcp_oauth.py` 中新增 Dashboard 模式的 OAuth flow builder，當 `HERMES_BASE_URL` 環境變數存在時，使用公開 URL 作為 OAuth redirect_uri，取代 Pod localhost。

## Acceptance Criteria

- [ ] 新增 `build_dashboard_oauth_flow(server_name, server_url, base_url, oauth_config)` 函式
- [ ] 函式執行 OAuth discovery (PRM + ASM metadata)
- [ ] 函式執行 Dynamic Client Registration (RFC 7591)，redirect_uri 為 `{base_url}/api/mcp/oauth/callback/{server_name}`
- [ ] 函式生成 PKCE code_verifier + code_challenge (S256)
- [ ] 函式回傳 `OAuthFlowState` dataclass：`authorization_url, code_verifier, state, client_info, server_url, storage`
- [ ] 新增 `exchange_code_for_token(flow_state, code)` 函式，使用 code + code_verifier 交換 token 並持久化

- [ ] 現有 `build_oauth_auth()` 和 CLI 流程不受影響 (backward compatible)

## Technical Details

### OAuthFlowState dataclass

```python
@dataclasses.dataclass
class OAuthFlowState:
    server_name: str
    authorization_url: str
    code_verifier: str
    state: str
    client_info: Any  # OAuthClientInformationFull
    server_url: str
    storage: HermesTokenStorage
    created_at: float  # time.time()
```

### build_dashboard_oauth_flow() 實作步驟

1. 建構 `HermesTokenStorage(server_name)`
2. 建構 `OAuthClientMetadata`:
   - `redirect_uris = [AnyUrl(f"{base_url}/api/mcp/oauth/callback/{server_name}")]`
   - `client_name = "Hermes Agent Dashboard"`
   - `grant_types = ["authorization_code", "refresh_token"]`
   - `response_types = ["code"]`
   - `token_endpoint_auth_method = "none"` (public client)
3. 使用 SDK 的 `discover_oauth_metadata()` 取得 PRM + ASM
4. 使用 SDK 的 `register_client()` 動態註冊（或載入已有 client_info）
5. 生成 PKCE: `code_verifier = secrets.token_urlsafe(43)`, `code_challenge = base64url(sha256(code_verifier))`
6. 構建 `authorization_url`:
   - `{authorization_endpoint}?response_type=code&client_id={client_id}&redirect_uri={redirect_uri}&state={state}&code_challenge={code_challenge}&code_challenge_method=S256&scope={scopes}`
7. 回傳 `OAuthFlowState`

### exchange_code_for_token() 實作步驟

1. 從 `flow_state` 取出 `code_verifier`, `client_info`, `storage`
2. POST `token_endpoint`:
   - `grant_type=authorization_code`
   - `code={code}`
   - `redirect_uri={redirect_uri}`
   - `code_verifier={code_verifier}`
   - `client_id={client_id}`
3. 解析 response → `OAuthToken`
4. 透過 `storage.set_tokens(token)` 持久化
5. 回傳成功/失敗

### 修改 _build_client_metadata()
