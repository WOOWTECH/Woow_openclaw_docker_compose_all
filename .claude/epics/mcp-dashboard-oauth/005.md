### golden-config.yaml 新增範例

```yaml
mcp_servers:
  Higgsfield:
    url: "https://mcp.higgsfield.ai/mcp"
    auth: oauth
    enabled: true
  # Pre-registered OAuth client example:
  FigmaMCP:
    url: "https://mcp.figma.com/mcp"
    auth: oauth
    oauth:
      client_id: "your-registered-client-id"
      scope: "read write"
    enabled: true
```

### 使用者手冊新章節

在 `docs/user-manual-zh-TW.md` 中新增：

```markdown
## 連接需要 OAuth 的 MCP Server

### 步驟 1：在 Dashboard 設定 MCP Server
進入 Settings → System → MCP Servers

### 步驟 2：點擊「授權登入」
對於需要 OAuth 認證的 server（如 Higgsfield），
會顯示「🔐 授權登入」按鈕

### 步驟 3：在彈出視窗中完成認證
瀏覽器會開啟 OAuth provider 的登入頁面

### 步驟 4：授權完成
認證成功後視窗自動關閉，Dashboard 顯示連線狀態
```
