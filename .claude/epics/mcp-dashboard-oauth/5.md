# Task: Integration Test — Dashboard → Higgsfield OAuth E2E

## Description

在 K8s 部署環境中進行端到端整合測試，驗證從 Dashboard 點擊「授權登入」到 Higgsfield MCP 連線成功的完整流程。包含部署修改後的 Agent/WebUI、設定 Higgsfield MCP server、執行 OAuth 流程、驗證 tool listing。

## Acceptance Criteria

- [ ] 修改後的 Agent 程式碼部署到 K8s Pod
- [ ] Dashboard MCP Panel 顯示 Higgsfield server + OAuth 按鈕
- [ ] 點擊按鈕 → popup 開啟到 Higgsfield OAuth 頁面
- [ ] 完成 Higgsfield 授權 → callback 回到 Hermes
- [ ] popup 自動關閉 → Dashboard 顯示成功
- [ ] Server list 刷新 → Higgsfield 顯示 Active + tool count
- [ ] Token 持久化到 `mcp-tokens/Higgsfield.json`
- [ ] CLI `hermes mcp login` 仍然正常運作 (regression)
- [ ] Token refresh 在 access_token 過期後自動完成

## Technical Details

### 部署步驟

1. **準備修改後的 Agent image**:
   - kubectl exec 到 Pod，patch mcp_oauth.py 和 web_server.py
   - 或者 build 新 image 並更新 Deployment

2. **準備修改後的 WebUI**:
   - kubectl exec 到 hermes-webui container
   - patch panels.js, style.css, i18n.js
   - 或者 mount ConfigMap overlay

3. **設定 Higgsfield MCP**:
   ```yaml
   # 在 config.yaml 中加入:
   mcp_servers:
     Higgsfield:
       url: "https://mcp.higgsfield.ai/mcp"
       auth: oauth
       enabled: true
   ```

4. **驗證 HERMES_BASE_URL**:
   ```bash
   kubectl --context woow-k3s -n hermes exec deploy/hermes -- printenv HERMES_BASE_URL
   # 預期: https://woowtech-hermes.woowtech.io
   ```

### API 驗證腳本

```bash
#!/bin/bash
DOMAIN="woowtech-hermes.woowtech.io"
BASE="https://$DOMAIN"

# T2: POST /auth should return authorization_url
echo "=== T2: Auth API ==="
curl -s -X POST "$BASE/api/mcp/servers/Higgsfield/auth" \
  -H "Content-Type: application/json" | python3 -m json.tool

# T8: Auth status
echo "=== T8: Auth Status ==="
curl -s "$BASE/api/mcp/servers/Higgsfield/auth/status" | python3 -m json.tool

# T7: Token file
echo "=== T7: Token File ==="
kubectl --context woow-k3s -n hermes exec deploy/hermes -- \
  ls -la /opt/data/.hermes/mcp-tokens/Higgsfield* 2>/dev/null || echo "No token files"
```
