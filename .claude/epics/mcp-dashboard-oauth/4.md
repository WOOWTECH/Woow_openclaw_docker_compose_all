# Task: WebUI — OAuth Button + Popup Flow

## Description

在 WebUI Dashboard 的 MCP Panel (`/app/static/panels.js`) 中新增 OAuth 授權按鈕和 popup 認證流程。修改 server row rendering，加入 CSS 樣式和 i18n 翻譯。

## Acceptance Criteria

- [ ] HTTP transport + 需要 OAuth 的 server 顯示「🔐 授權登入」按鈕
- [ ] 已認證但 status 異常的 server 顯示「⚠ 重新授權」按鈕
- [ ] 已認證且 active 的 server 不顯示按鈕
- [ ] 點擊按鈕後呼叫 `POST /api/mcp/servers/{name}/auth`
- [ ] 收到 `authorization_url` 後開啟 600x700 popup
- [ ] popup 被阻擋時顯示 toast 提示
- [ ] popup 關閉後輪詢 `GET /api/mcp/servers/{name}/auth/status`
- [ ] 認證成功 → 顯示 success toast + 刷新 server list
- [ ] 認證失敗 → 顯示 error toast
- [ ] i18n key 完整（中/英）

## Technical Details

### 1. panels.js 修改 — loadMcpServers() 中的 server row

在現有 `loadMcpServers()` 函式的 server row rendering 邏輯中，於 `mcp-server-meta` div 內加入 OAuth 按鈕：

```javascript
// 在 server row rendering 中 (約 line 12680):
// 判斷條件：HTTP transport + auth === 'oauth' 或 status 包含 unauthorized
const needsOAuth = s.transport === 'http' && (
  s.auth === 'oauth' ||
  s.status === 'unauthorized' ||
  s.status === 'invalid_config'
);
const isAuthenticated = s.status === 'active' && s.auth === 'oauth';
const tokenExpired = s.auth === 'oauth' && s.status !== 'active';

if (needsOAuth && !isAuthenticated) {
  // 未認證 → 授權登入按鈕
  metaHtml += `<button class="mcp-oauth-btn" onclick="mcpOAuthLogin('${s.name}')">${t('mcp_oauth_login')}</button>`;
} else if (tokenExpired) {
  // Token 過期 → 重新授權按鈕
  metaHtml += `<button class="mcp-oauth-btn mcp-oauth-btn-reauth" onclick="mcpOAuthLogin('${s.name}')">${t('mcp_oauth_reauth')}</button>`;
}
```

### 2. panels.js 新增 — mcpOAuthLogin() 函式

```javascript
async function mcpOAuthLogin(serverName) {
  try {
    const res = await api('/api/mcp/servers/' + encodeURIComponent(serverName) + '/auth', {
      method: 'POST',
    });

    if (!res || !res.ok) {
      showToast(res?.error || t('mcp_oauth_failed'), 'error');
      return;
    }

    if (res.mode !== 'dashboard' || !res.authorization_url) {
      showToast(t('mcp_oauth_no_dashboard'), 'error');
      return;
    }

    // 開啟 popup
    const popup = window.open(
      res.authorization_url,
      'mcp_oauth_' + serverName,
      'width=600,height=700,scrollbars=yes,resizable=yes'
    );

    if (!popup || popup.closed) {
      showToast(t('mcp_oauth_popup_blocked'), 'error');
      return;
    }

    showToast(t('mcp_oauth_waiting'), 'info');

    // 輪詢等待 popup 關閉
    const pollInterval = setInterval(async () => {
      if (popup.closed) {
        clearInterval(pollInterval);

        // 檢查認證狀態
        try {
          const status = await api(
            '/api/mcp/servers/' + encodeURIComponent(serverName) + '/auth/status'
          );
          if (status && status.authenticated) {
            showToast(
              t('mcp_oauth_success', serverName) +
              (status.tools_count ? ' (' + status.tools_count + ' tools)' : ''),
              'success'
            );
          } else {
            showToast(t('mcp_oauth_failed'), 'error');
          }
        } catch (e) {
          showToast(t('mcp_oauth_failed'), 'error');
        }

        // 刷新 server list
        loadMcpServers();
      }
    }, 1000);

    // 5 分鐘超時保護
    setTimeout(() => {
      clearInterval(pollInterval);
      if (!popup.closed) popup.close();
    }, 300000);

  } catch (e) {
    showToast(t('mcp_oauth_failed'), 'error');
  }
}
```
