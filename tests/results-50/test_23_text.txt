## /tmp 專案文件摘要

### 1️⃣ 專案需求規格書 (proj_req.docx)

| 項目 | 內容 |
|------|------|
| **專案名稱** | 智慧建築物聯網管理平台 |
| **版本** | v1.0 |
| **日期** | 2026-07-11 |
| **建立者** | WoowTech Smart Space Solution |

**核心目標**：整合 KNX 智慧家居、Home Assistant、Odoo ERP，實現能源管理、設備監控、業務流程自動化。

**功能需求**：
- **能源管理**：即時用電監控、儀表板、節能建議
- **設備控制**：KNX 整合（燈光/空調/窗簾/暖氣）、情境模式、排程控制
- **空間管理**：會議室預約、佔用偵測、環境監測（溫濕度/CO2）
- **資料分析**：用電分析、異常告警、報告產出

**非功能需求**：
- 效能：回應 < 2 秒、同時在線 > 50 人
- 安全：TLS 1.3、MFA、RBAC
- 可用性：99.5% 可用率、7x24 小時、響應式設計

**技術架構**：AWS/Azure + Raspberry Pi 5 (HA Core) + KNX/Basalte + Odoo 18 + PostgreSQL

**里程碑**：需求確認(08-01) → 系統設計(09-15) → 開發完成(12-01) → UAT(01-15) → 上線(02-01)
